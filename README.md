# 🐭 LAB MICE

같은 색 쥐와 치즈를 잇되 **모든 칸을 채워야** 하는 길 잇기 퍼즐 게임입니다.

- **게임 화면**: GitHub Pages (이 저장소)
- **기록 저장**: Google Apps Script + 구글 시트 (`apps-script/Code.gs`)

```
index.html            게임 첫 화면
css/style.css         디자인
js/config.js          ★ Apps Script 주소(API_URL) 넣는 곳
js/app.js             게임 화면·조작·별점·교사 모드
js/labmice-core.js    규칙 + 자동 풀이기
js/puzzles.js         문제 30개 (자동 생성 파일)
js/api.js             Apps Script와 통신
tools/generator.html  문제 다시 만들기 (브라우저에서 실행)
apps-script/Code.gs   Apps Script에 붙여넣을 서버 코드
```

## 레벨 구성

| 레벨 | 이름 | 판 | 새 장치 |
|---|---|---|---|
| 0 | 치즈 연습실 | 5×5 | 기본 규칙 |
| 1 | 기초 연구실 | 6×6 | 쥐와 치즈가 붙어 있지 않음 |
| 2 | 미로 연구실 | 7×7 | 🧱 벽 |
| 3 | 덫 연구실 | 7×7 | 🪤 덫 (못 지나가는 칸) |
| 4 | 일방통행 연구실 | 8×8 | ➜ 화살표 방향으로만 나감 |
| 5 | 시약 연구실 | 9×9 | 🧪 같은 색 쥐가 꼭 지나가야 하는 칸 |

모든 문제는 자동 풀이기로 **해답이 정확히 1개**임을 확인했고, 후보 중 풀이기가 가장 오래 고민한 문제를 골랐습니다.

## 별점

- 실수 = 되돌리기 1 + 길 지우기 1 + 처음부터 2
- 실수가 기준을 넘으면 별 −1 / −2, 목표 시간을 넘기면 별 −1 (시간 표시가 꺼져 있으면 시간은 안 봄)
- 힌트 2단계(점선 미리보기) → 최대 ⭐⭐, 힌트 3단계(한 색 대신 그려 줌) → 최대 ⭐

## 배포 방법

### 1. Apps Script (기록 저장)

1. 기존 LAB MICE Apps Script 프로젝트를 열고 `Code.gs` 내용을 `apps-script/Code.gs`로 **전부 바꿉니다**.
   `Index.html` 파일은 더 이상 쓰지 않으니 지워도 됩니다.
2. 함수 `setupLabMice`를 한 번 실행합니다 (권한 허용).
3. **프로젝트 설정(⚙️) → 스크립트 속성**에서 `TEACHER_PASSWORD`를 원하는 비밀번호로 바꿉니다.
4. **배포 → 새 배포 → 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
5. 나온 `https://script.google.com/macros/s/.../exec` 주소를 복사합니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영돼요.
> (새 배포를 만들면 주소가 바뀝니다.)

### 2. GitHub Pages (게임 화면)

1. `js/config.js`의 `API_URL`에 위 주소를 붙여넣습니다.
2. 이 폴더 전체를 GitHub 저장소에 올립니다.
3. 저장소 **Settings → Pages → Branch: main / (root)** 를 선택하고 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 게임이 열립니다.

`API_URL`을 비워 두면 오프라인 모드로 동작합니다(기록은 학생 기기에만 저장, 모든 레벨 공개 설정 상태, 교사 모드 사용 불가).

## 문제 새로 만들기

`tools/generator.html`은 브라우저에서 열어야 하는데, 파일을 그냥 더블클릭하면 스크립트가 안 불러와질 수 있어요.
GitHub Pages에 올린 뒤 `https://<아이디>.github.io/<저장소이름>/tools/generator.html` 로 열면 됩니다.

seed 숫자를 바꾸고 **문제 만들기** → 내려받은 `puzzles.js`로 `js/puzzles.js`를 바꿔 올리면 끝.
(seed 2026이 지금 들어 있는 문제입니다. 문제를 바꾸면 학생 기록의 문제 번호와 내용이 달라지니 학기 중에는 바꾸지 않는 걸 추천해요.)

난이도 조절은 `tools/generator.js` 맨 위 `LEVEL_SPECS`에서 합니다
(판 크기 `rows/cols`, 쌍 수 `pairs`, 덫 수 `traps`, 장치 최대 개수 `budget`, 후보 수 `pool` — 쌍이 적을수록, 후보가 많을수록 어려워져요).

## 알아 둘 점

- 저장소가 공개(public)면 문제의 정답 데이터도 공개됩니다. 초등 수업용으로는 큰 문제가 아니지만, 신경 쓰이면 저장소를 비공개로 두고 GitHub Pages를 쓰는 방법(유료 플랜)이 필요해요.
- 교사 비밀번호는 코드가 아니라 Apps Script **스크립트 속성**에 있어서 저장소에 올라가지 않습니다.
- 학생 기록은 `labMice2_` 이름으로 브라우저에 저장됩니다. 주소(도메인)가 바뀌면 브라우저 기록은 새로 시작돼요.
